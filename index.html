How to read this comparison

Requests are grouped by method and normalized URL. Repeated requests are compared as a group, using counts, body-byte totals, HTTP error counts, and median duration. Query parameters are included in matching unless you explicitly ignore them above. Their values are hidden in displayed URLs.

Missing or negative HAR measurements are unknown, not zero. Coverage is shown alongside the metrics. Response body bytes are not total network transfer or page weight.

Two captures show observations, not proof of a performance regression or its cause. Cache state, network conditions, device load, and user actions can change the result. Capture the same flow under similar conditions and repeat before drawing conclusions.
